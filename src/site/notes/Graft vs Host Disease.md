## Pathophysiology
Occurs due to host immunodeficiency
- Grafted [[T-cells\|T-cells]] proliferate and reject Host proteins
- Type IV Hypersensitivity Reaction

## Clinical Features
1. Maculopapular rash
2. Jaundice
3. Diarrhoea
4. Jaundice, hepatosplenomegaly

// Potentially beneficial in bone marrow transplant due to graft-vs-tumor effect
