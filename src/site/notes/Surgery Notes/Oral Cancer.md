Usually arises from lateral border of tongue also from Cheeks, floor and gums

### Premalignant conditions
1. Leukoplakia
2. Erythroplakia
3. Chronic hyperplastiuc candidiasis
4. Submucous fibrosis
5. Sideropenic dysphagia
6. Papillomam tongue/neck
7. Discoid [[Medicine notes/Systemic Lupus Erythematosus\|SLE]]
8. Dysketatosis congenita
9. Syphillitic glossitis
10. [[OBGY Notes/HPV Infection\|HPV Infection]]
11. Environmental factors - UV, Smoking, Reverse smoking

## Clinical Features
Depends on site of tumour
1. Carcinoma of Buccal mucosa
2. Carcinoma of Tongue

## Staging
| Primary Tumour(T)             | Regional Lymph Node(N)                    | Distant Metastasis(M) |
| ----------------------------- | ----------------------------------------- | --------------------- |
| T0 - No evidence              | Nx - Not assessable                       | M0 - No               |
| Tis - In-situ                 | N0 - None                                 | M1 - Yes              |
| T1 - <2cm                     | N1 - Single, Ipsilateral, <3cm            |                       |
| T2 - 2-4cm                    | N2a - Single Ipsilateral, 3-6cm           |                       |
| T3 - >4cm                     | N2b - Multiple ipsilateral but <6cm       |                       |
| T4 - Invading local structure | N2c - Contralateral or bilateral but <6cm |                       |
|                               | N3 - >6cm                                 |                       |
Stage 1 - $T_1$
Stage 2 - $T_2$
Stage 3 - $T_3$ or $N_1$
Stage 4 - $T_4$ or $N_{2-3}$ or $M_1$

## Treatment
1. Chemotherapy
2. Radiotherapy
3. Wide excision with removal of bone
4. Palliative surgery for advanced disease
5. Radical n eck dissection for lymph nodes
6. Pectoralis Major Myocutaneous Flap
