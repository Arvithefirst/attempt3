| Score | Dilatation | Effacement | Station | Consistency | Position  |
| ----- | ---------- | ---------- | ------- | ----------- | --------- |
| 0     | Closed     | <30%       | -3      | Firm        | Posterior |
| 1     | 1-2cm      | <50%       | -2      | Medium      | Middle    |
| 2     | 3-4cm      | <70%       | -1 or 0 | Soft        | Anterior  |
| 3     | >4cm       | >70%       | >0      |             |           |
