False vs True labour pains

| False labour                  | True Labour                       |
| ----------------------------- | --------------------------------- |
| Dull in nature                | Occur at regular intervals        |
| Confined to lower abdomen     | Gradually increasing in intensity |
| Relieved by enema or sedative | Associated with "*show*"          |
|                               | Progressive effacement of cervix  |
|                               | Descent of presenting part        |
|                               | "*Bag of forewaters*"             |
|                               | Not relieved by enema/sedative    |

*Show* - Expulsion of cervical mucuc plug with blood at onset of true labour
*Bag of forewaters* - Due to stretching of the lower segment of uterus, sometimes the membranes come loose, bulge into the cervical canal and fill up with amniotic fluid.
