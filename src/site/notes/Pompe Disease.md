# Pompe Disease
Type II [[Glycogen Metabolism\|Glycogen Storage Disorders]]

$$\text{Deficiency of Lysosomal acid } \alpha \text{-1,4-glucosidase (Acid Maltase)}$$
## Clinical Features
1. Cardiomyopathy
2. Hypotonia
3. Exercise intolerance
4. enlarged tongue
