# IPEX Syndrome
Stands for 
- Immune Dysregulation
- Polyendocrinopathy
- Enteropathy
- X-linked
Syndrome

## Clinical Features
Mutation on FOXP3 gene
- [[DM type 1\|DM type 1]] in male infants
- Enteropathy
- Endocrinopathies
- Nail dystrophy, Dermatitis
