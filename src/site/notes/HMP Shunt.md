# HMP Shunt

![Screenshot 2026-09-04 at 11.34.28 PM.png](/img/user/Screenshot%202026-09-04%20at%2011.34.28%20PM.png)

Provides NADPH used for
- Glutathione reductase in RBCs
- Fatty acid and [[Cholesterol synthesis\|Cholesterol synthesis]]

Also provides Ribose-5-phosphate for [[Nucleotide synthesis\|Nucleotide synthesis]]

Defect in Glucose-6-P dehydrogenase causes [[G6PD deficiency\|G6PD deficiency]]
