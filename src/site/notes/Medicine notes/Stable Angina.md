Also called Angina Pectoris it is central chest pain, discomfort or [[Medicine notes/Breathlessness\|Breathlessness]] caused by transient myocardial ischemia that occurs when there is myocardial oxygen supply imbalance.
# Etiology
1. Artherosclerosis
2. Aortic valve diseases
3. Hypertrophic cardiomyopathy
4. Coronary Artery spasm (Variant Angina or Prinzmetals angina)
5. Syndrome X(seen in women despite normal coronaries)

# Clinical features
Central chest pain, discomfort or [[Medicine notes/Breathlessness\|Breathlessness]] precipitated by exercise. May only occur in the start(warm up angina)

<mark style="background: #FF5582A6;">Canadian Cardiovascular Society Angina Scoring</mark>

| Class | Description                                                      |
| ----- | ---------------------------------------------------------------- |
| I     | Angina only during strenuous or prolonged physical activity      |
| II    | Slight limitation of activity                                    |
| III   | Moderate limitation of activity(interferes with normal activity) |
| IV    | Inability ot perform any activity                                |

# Investigations
1. ECG / Stress ECG (looking for >1mm ST depression)
2. Stress electrocardiography
3. Myocardial perfusion scanning
4. CT Coronary Artery

# Management
1. LIFESTYLE CHANGES GO KILL YOURSLEF
2. Aspirin or Clopidogrel
3. Anti-Anginal drugs
	1. Nitrates - GTN
	2. B-blockers(cardioselective) - Metoprolol, bisoprolol
	3. CCBs - Nifedipine, Amlodipine
	4. Potassium channel activator - Nicorandil
	5. If channel antagonist - Ivabradine
	6. Ranolazine
4. Percutaneous Coronary Intervention
5. Coronary Artery Bypass Grafting
