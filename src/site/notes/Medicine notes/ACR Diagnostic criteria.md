American College of Rheumatology(ACR) / European league against Rheumatism(EuLAR) diagnostic criteria for [[Medicine notes/Rheumatoid Arthritis\|Rheumatoid Arthritis]]

| Domain                | Criteria             | Score |
| --------------------- | -------------------- | ----- |
| Joints affected       | 1 large joint        | 0     |
|                       | 2-10 large joints    | 1     |
|                       | 1-3 small joints     | 2     |
|                       | 4-10 small joints    | 3     |
|                       | >10 small joints     | 5     |
| Serology              | RF and ANCA -ve      | 0     |
|                       | Low positive either  | 2     |
|                       | High positive either | 3     |
| Duration              | <6 weeks             | 0     |
|                       | >6 weeks             | 1     |
| Acute Phase reactants | Normal               | 0     |
|                       | Raised               | 1     |
Patients with >6 have definite [[Medicine notes/Rheumatoid Arthritis\|Rheumatoid Arthritis]]
